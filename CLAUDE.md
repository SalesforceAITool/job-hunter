# Working rules from the owner

## Reuse first, never build from scratch
For every request, before designing or writing anything:
1. Check what already exists for free: open-source projects on GitHub, free tiers, free models, existing apps.
2. Prefer cloning/forking an existing project and extending it over writing new code.
3. Write new code only for the gap that no existing free resource covers, and say why.
4. Always report which existing resources were checked and which one was picked.

## Plan before building
For anything bigger than a small fix: plan first. Review the architecture from several angles
(e.g. a small team of architects with different lenses), confirm the plan is feasible
(especially "can this be done for free?"), then develop, test, and push to GitHub.
Avoid back-and-forth later about "this can't be done".
